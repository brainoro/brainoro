🚀 What Problem Does Brainoro Solve?

Traditional educational software suffers from two massive structural flaws:

  1. Rigid Schema Constraints: Legacy platforms hardcode their subjects and boards, causing catastrophic rewrites whenever scaling from CBSE to Cambridge or IB MYP.
  2. Rote-Learning Burnout: Traditional tests award opaque percentages (e.g. "72%") that measure short-term cramming rather than long-term conceptual retention.

The Brainoro Breakthrough: Brainoro decouples mathematical cognitive algorithms (Spaced Repetition, Item Response Theory, DAG Concept Lineage) from syllabus metadata. It delivers measurable cognitive acceleration across any national or international curriculum.

⚡ 1. How to Launch & Run Brainoro

Brainoro consists of two decoupled components: a modern Next.js frontend and a high-performance Python FastAPI engine.

Start Frontend:

cd C:\Users\pali0\Brainoro\frontend
npm run dev

Or simply double-click: C:\Users\pali0\Brainoro\start_frontend.bat
Accessible in your browser at: http://localhost:3000

Start Backend (FastAPI Engine):

cd C:\Users\pali0\Brainoro\backend
.\venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000

Or simply double-click: C:\Users\pali0\Brainoro\start_backend.bat
Interactive API Documentation (Swagger): http://localhost:8000/docs

🎓 3. Dynamic Board Matrix (CBSE vs Cambridge vs IB MYP)

When you switch boards at the top of the screen, the interface completely changes its rules:

  • CBSE Matrix: Calculation Locks active. Step-by-step sequential proofs required. Reflects CBSE examiner standards where final answers without derivations receive 0 marks.
  • Cambridge (CIE) Matrix: Command Words active (Calculate, Deduce, State, Explain). Built-in Scientific Calculator window with 3 significant figures precision checks.
  • IB MYP Matrix: Criteria A–D holistic rubrics (Knowing & Understanding, Inquiring & Designing, Processing & Evaluating, Reflecting on Impacts) mapped directly to official 1–7 scale bands.

📥 4. Open Educational Resources (OER) Ingestion

Brainoro lets you ingest open-source Creative Commons textbooks (OpenStax and CK-12 FlexBooks) to generate 100% original owned IP.

  1. Click "Ingest OER" in the top-right corner.
  2. Set Target Board (e.g. CBSE), Subject (e.g. Physics), and Grade.
  3. Enter your Topic Tracking Key (e.g. LIGHT).
  4. Paste raw textbook markdown into the box.
  5. Click "Execute Ingestion".
  6. The system dynamically maps the key as CBSE-G9-PHYSICS-LIGHT, registers the node, and generates the lesson blueprint!
